แหล่งภาพที่ใช้ได้

  • กล้องมือถือและแท็บเล็ต: ปุ่ม ถ่ายภาพ ในหน้าถ่ายภาพส่งตรวจ ไม่ต้องตั้งค่าอะไร
  • เว็บแคมของคอมพิวเตอร์หรือกล้อง USB: ปุ่ม ใช้เว็บแคมของเครื่องนี้ เบราว์เซอร์อนุญาตเฉพาะเมื่อเปิดระบบผ่าน https หรือ localhost
  • กล้อง IP: ลงทะเบียนในหน้านี้ ผู้ที่มีสิทธิ์ สั่งถ่ายจากกล้อง IP จะเห็นปุ่มถ่ายในหน้าถ่ายภาพส่งตรวจ หรือให้โปรแกรมถ่ายตามเวลาโดยอัตโนมัติ

โปรแกรมกล้องบนเครื่องในโรงงาน

{{ 'เชื่อมต่ออยู่' if agent_online else 'ไม่ได้เชื่อมต่อ' }}

ระบบบน cloud มองไม่เห็นกล้องในเครือข่ายโรงงาน จึงใช้โปรแกรมเล็ก ๆ ชื่อ tools/camera_agent.py รันบนคอมพิวเตอร์ในโรงงานเครื่องหนึ่ง โปรแกรมจะดึงภาพจากกล้องแล้วส่งขึ้นมาให้

{% if token %}

ถ่ายตามตารางเวลาที่ตั้งในหน้านี้ แยกรายกล้องและรายแผนก (แนะนำ) โปรแกรมรับตารางจากระบบเอง แก้ตารางที่หน้าเว็บได้โดยไม่ต้องแตะเครื่องในโรงงาน

python camera_agent.py --server {{ s.public_url or 'https://ที่อยู่เว็บของระบบ' }} --token {{ token }}

แบบเดิม: ถ่ายทุกกล้องพร้อมกันตามเวลาที่ระบุในคำสั่ง (ไม่ใช้ตารางในหน้านี้)

python camera_agent.py --server {{ s.public_url or 'https://ที่อยู่เว็บของระบบ' }} --token {{ token }} --times 09:30,14:30

สุ่มเวลาถ่ายวันละ 2 ครั้งในช่วงเวลางาน แผนกจะเตรียมพื้นที่ล่วงหน้าไม่ได้

python camera_agent.py --server {{ s.public_url or 'https://ที่อยู่เว็บของระบบ' }} --token {{ token }} --random 2 --between 08:30-16:30

รับคำสั่งถ่ายจากปุ่มในหน้าเว็บด้วย (โปรแกรมจะถามระบบทุก 20 วินาทีในช่วงเวลาที่กำหนด)

python camera_agent.py --server {{ s.public_url or 'https://ที่อยู่เว็บของระบบ' }} --token {{ token }} --times 09:30,14:30 --listen 08:00-17:00
