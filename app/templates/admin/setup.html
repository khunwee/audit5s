4 ข้อแรกจำเป็นก่อนเริ่มตรวจ ข้อที่เหลือเพิ่มได้ภายหลัง

  1. {{ 'เสร็จแล้ว: ' if done.ai }}ใส่ API key ของ AI แล้วกดทดสอบด้วยภาพตัวอย่าง{% if not done.ai and s.ai1_type == 'demo' %} (ตอนนี้เป็นโหมดทดลอง คะแนนไม่ใช่ของจริง){% endif %}
  2. {{ 'เสร็จแล้ว: ' if done.depts }}เพิ่มแผนกที่เข้าร่วม{% if done.depts %} ({{ done.depts }} แผนก){% endif %}
  3. {{ 'เสร็จแล้ว: ' if done.users and done.verifier }}สร้างบัญชีผู้ใช้ของตัวแทนแผนก และเปิดสิทธิ์ยืนยันผลให้หัวหน้าหรือกรรมการอย่างน้อย 1 คน{% if done.users and not done.verifier %} (ยังไม่มีบัญชีที่ยืนยันผลได้นอกจากผู้ดูแล){% endif %}
  4. {{ 'เสร็จแล้ว: ' if done.round }}สร้างรอบการตรวจรอบแรก ใส่วันสิ้นสุดและติ๊กปิดรอบเอง รอบถัดไประบบสร้างให้ทุกเดือน
  5. {{ 'เสร็จแล้ว: ' if done.areas }}กำหนดจุดตรวจของแต่ละแผนก (ไม่บังคับ ถ้าไม่กำหนด ผู้ส่งภาพพิมพ์ชื่อจุดเอง)
  6. {{ 'เสร็จแล้ว: ' if done.channel }}ตั้งช่องทางแจ้งเตือนของผู้ดูแล (ไม่บังคับ)
  7. {{ 'เสร็จแล้ว: ' if done.cameras }}ลงทะเบียนกล้อง IP (ไม่บังคับ ใช้มือถือถ่ายได้ทันที)

ควรรู้ก่อนเริ่ม

  • ชุดตั้งค่าเป็นจุดเริ่มต้น ไม่ใช่มาตรฐานตายตัว อ่านรายการตรวจเทียบกับใบตรวจ 5ส ของหน่วยงาน แล้วแก้ข้อความ แต้ม หรือปิดข้อที่ไม่ใช้ที่หน้า รายการตรวจ
  • ชุดตั้งค่าเปิด นับคะแนนเฉพาะภาพที่ยืนยันแล้ว คะแนนจึงยังไม่ขึ้นจนกว่าหัวหน้าหรือกรรมการจะยืนยันผลที่เมนู ยืนยันผล ปิดได้ที่หน้า ตั้งค่าและ AI
  • ลองกับรอบทดสอบก่อน: ให้กรรมการตัดสินภาพชุดเดียวกับ AI แล้วดูหน้า ความแม่นของ AI ว่าข้อใดควรเขียนให้ชัดขึ้น
  • การแก้หมวดหรือรายการตรวจมีผลกับรอบที่สร้างใหม่ รอบที่เปิดอยู่ใช้ชุดเดิมจนกว่าจะกด ใช้เกณฑ์ล่าสุดกับรอบนี้
